下面给出一个**可同时代理任意 \*.huawei.com 子域**的完整示例。思路是：

- 让门户始终通过 **IP + HTTPS** 打开（或临时自签证书）。
- 用户在 iframe 里写 `/proxy/ssc.huawei.com/`、`/proxy/w3.huawei.com/`……Nginx 用正则把子域提取出来转成上游地址。
- **不改 Cookie 域**，只追加 `SameSite=None; Secure`；这样浏览器既能在 iframe 带 Cookie，也能在单独标签页访问同域时复用登录态。
- 统一注入 `frame-ancestors 'self'`，并移除所有阻止嵌套的旧头。

---

## 目录结构

```text
nginx-portal/
├── docker-compose.yml
├── conf.d/
│   └── proxy_any_huawei.conf
└── certs/
    ├── portal.crt
    └── portal.key
```

---

## 1 docker-compose.yml

```yaml
version: '3.9'

services:
  portal:
    image: node:20-alpine
    container_name: portal
    working_dir: /app
    volumes:
      - ./portal:/app
    command: ['npm', 'run', 'start']
    environment:
      - PORT=3000
    expose: ['3000']

  nginx-ui:
    image: uozi/nginx-ui:latest
    container_name: nginx-ui
    restart: unless-stopped
    depends_on: [portal]
    ports:
      - '80:80' # 强制跳转到 443
      - '443:443' # HTTPS：用 IP 打开
      - '8080:8080' # Web UI
    environment:
      - TZ=Asia/Shanghai
      - UI_AUTH=admin:changeme
    volumes:
      - ./conf.d:/etc/nginx/conf.d
      - ./certs:/etc/nginx/certs:ro
      - ./nginx-ui-data:/etc/nginx-ui
```

## 2 conf.d/proxy_any_huawei.conf

```nginx
# --------------------- 入口：HTTPS（直接用服务器 IP） ---------------------
server {
    listen 443 ssl http2;
    server_name _;

    ssl_certificate     /etc/nginx/certs/portal.crt;
    ssl_certificate_key /etc/nginx/certs/portal.key;

    # ---- 门户自身 ----
    location / {
        proxy_pass http://portal:3000/;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto https;
    }

    # ---- 通用代理：/proxy/<host>/   ->   https://<host>/ ----
    # 只允许 *.huawei.com，避免滥用
    location ~* ^/proxy/(?<sub>[-a-z0-9]+\.huawei\.com)(?<rest>/.*)?$ {
        set $target $sub$rest;                 # #1 拼回完整路径
        proxy_pass https://$target;            # #2 转到对应子域

        proxy_set_header Host              $sub;               # 保持原 Host
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto https;

        # ① 删除拒绝嵌套的老头
        proxy_hide_header X-Frame-Options;
        proxy_hide_header Content-Security-Policy;

        # ② 统一给所有 cookie 加 SameSite=None; Secure
        proxy_cookie_flags ~ SameSite=None Secure;

        # ③ 给父页面声明允许 iframe
        add_header Content-Security-Policy "frame-ancestors 'self'" always;
    }
}

# --------------------- HTTP 强制跳 HTTPS ---------------------
server {
    listen 80;
    server_name _;
    return 301 https://$host$request_uri;
}
```

### 使用方式

- 在门户代码里写：

  ```html
  <!-- 代理 ssc.huawei.com -->
  <iframe src="/proxy/ssc.huawei.com/" width="100%" height="800"></iframe>

  <!-- 代理 w3.huawei.com 下任意路径 -->
  <iframe src="/proxy/w3.huawei.com/workbench/index.html"></iframe>
  ```

## 3 自签证书（首次执行）

```bash
mkdir -p certs
openssl req -x509 -nodes -days 3650 \
  -subj "/CN=portal.local" \
  -newkey rsa:2048 \
  -keyout certs/portal.key \
  -out certs/portal.crt
```

把 `portal.crt` 导入浏览器信任根后，`Secure` Cookie 就能被接收。

---

## 4 启动 & 验证

```bash
docker compose up -d
```

1. 浏览 `https://<服务器IP>:8080` → 登录 Nginx-UI 可随时改配置并 Reload
2. 在浏览器新标签页先登录 `https://ssc.huawei.com`（可选）
3. 刷新门户，iframe 若直接展示业务页（非登录页）即说明 Cookie 已带上
4. DevTools→Network→任一 `/proxy/ssc.huawei.com/...` 请求，看 **Request Cookies** 是否存在

## 关键点与可扩展性

| 诉求                       | 设计                                                                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **多子域**                 | 用正则 `^/proxy/(?<sub>…\.huawei\.com)` 捕获子域，`proxy_pass https://$sub$rest` 动态转发                                                  |
| **安全限制**               | 正则只允许 `*.huawei.com`，避免被利用去反代外网                                                                                            |
| **Cookie 兼容**            | 不改 `Domain`，只统一 `SameSite=None; Secure`，所以同浏览器中直开子域也能共享会话                                                          |
| **未来私有 CA / 正式证书** | 替换 `portal.crt/key` 即可；或直接换成 Nginx Proxy Manager 并在 UI 申请 Let’s Encrypt                                                      |
| **第三方 Cookie 退场**     | Chrome 沙盒完成后可把 `proxy_cookie_flags` 换成 `Partitioned`（CHIPS），或将门户迁到 `portal.huawei.com`，把 `Domain=.huawei.com` 交给后端 |

---

> 复制以上文件、替换自己的 Next.js 项目路径后，`docker compose up -d` 即可让任何 \***.huawei.com** 子域在你的 IP 门户 iframe 中登录可用，而无需事先知道有哪些子域。
